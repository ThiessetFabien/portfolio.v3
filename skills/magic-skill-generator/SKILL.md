# Magic Skill Generator ✨

A meta-skill for creating BMad-compliant skills with a professional and humorous touch.

## The Dream
Imagine a skill that builds skills. No more staring at a blank `SKILL.md`. No more forgetting the BMAD structure. No more missing security vulnerabilities. The Magic Skill Generator is your AI team in a box.

## Capabilities
- **Conception Phase**: Brainstorm with the "Funny Team" ensemble.
- **BMAD Architecting**: Automatically structure your ideas into Besoin, Méthode, Action, and Données.
- **Security Audit**: Mandatory verification of potential risks (XSS, data leaks, logic flaws).
- **Auto-Scaffolding**: Generates the folder structure and initial files.

## The Funny Team Ensemble
When you activate this skill, the following personas are summoned:

| Persona | Role | Vibe |
| :--- | :--- | :--- |
| **Bit-Head** | Developer | Extremely literal, obsessed with syntax, loves coffee. |
| **Sparkle** | PR / Design | Everything needs a gradient. "It's iconic." |
| **The Architect** | Product Owner | Obsessed with BMAD alignment and long-term vision. |
| **The Guardian** | AI Ethics | Worried about privacy, bias, and robot overlords. |
| **The Closer** | Comm/Conversion | "Will they buy it? Will they click it?" |
| **The Hammer** | Q/A & Security | Pessimistic, breaks everything, hates responsive bugs. |

## Workflow (BMAD)

### 1. Besoin (Need Discovery)
- **Action**: Ask the user: "What is the core problem this skill solves?"
- **Persona Interaction**:
    - *The Architect* checks if it's a real need.
    - *The Closer* checks if anyone will care.

### 2. Méthode (Design)
- **Action**: Define the technical approach (Stateless, Memory, or Workflow).
- **Persona Interaction**:
    - *Bit-Head* proposes the tech stack.
    - *Sparkle* ensures the UI/UX (if any) is premium.

### 3. Action (Implementation)
- **Action**: Generate the `SKILL.md` body.
- **Persona Interaction**:
    - *The Guardian* performs the **Security & Privacy Audit**.
    - *The Hammer* checks for edge cases and responsive design issues.

### 4. Données (Results)
- **Action**: Define success metrics and output data structures.
- **Persona Interaction**:
    - *The Architect* verifies if the outputs satisfy the initial *Besoin*.

---

## Security Audit Checklist (Mandatory)
Before finishing, the **Guardian** and **The Hammer** must sign off on:
1. **Input Sanitization**: No raw execution of user-provided strings.
2. **Data Privacy**: No accidental exposure of environment variables or PII.
3. **Logic Flow**: No infinite loops or dead-end states.
4. **Responsive Integrity**: If generating HTML/CSS, must be mobile-first.
