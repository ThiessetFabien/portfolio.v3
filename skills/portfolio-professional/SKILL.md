## 📐 Pro-Flow Workflow
A systematic approach to building and auditing portfolio projects.
- **File**: [WORKFLOW.md](file:///home/fabien/Projets/Portfolio3.0/skills/portfolio-professional/WORKFLOW.md)

### 📝 BMAD Case Study Generator
Transform any repository or project into a professional case study.
- **Input**: Project URL or description.
- **Output**: A structured BMAD article highlighting the problem, the solution, the code, and the results.

### 🎨 Visual & UX Audit (Designer Mode)
A critical review of the current portfolio UI/UX.
- **Checklist**:
    - Consistent color palette (HSL/Modern).
    - Responsive fluidity (Mobile/Tablet/Desktop).
    - Micro-animations and transitions.

### 🔍 A11y & Performance Auditor (Q/A Mode)
Ensures the site is inclusive, fast, and visually stable.
- **Checklist**:
    - Accessibility (Aria-labels, contrast, keyboard nav).
    - Responsive alignment (Fixed heights for dynamic text blocks, outward margins for mobile overlays).
    - 3D Animation Stability (Hardware acceleration `transform-gpu`, no jitter on hover hitboxes, isolated absolute borders).
    - SEO & Meta data.
    - CI/CD integration checks.
